# Zebella Designs — storefront

Next.js storefront. All data and business logic (catalog, auth, cart, orders, payments) live in the
separate Python backend; this app only talks to it through `src/lib/api/client.ts`.

## Setup

```bash
cp .env.example .env.local   # set NEXT_PUBLIC_API_URL to the backend base URL
npm install
npm run dev
```

## Demo mode (no backend yet)

If `NEXT_PUBLIC_API_URL` is not set, the storefront runs on built-in sample data so it can be shown to clients:
6 collections, 24 products (anarkalis, frocks, salwar sets, cord sets, gowns), home-page content, banners,
testimonials, policies, FAQ and two sample orders. Sign-in accepts **any username and password**; the cart,
wishlist and profile are kept in the browser; checkout/payment is switched off. Coupon `WELCOME10` gives 10% off.

- Data: `src/lib/mock/specs.ts` (catalogue) and `src/lib/mock/data.ts`; fake API: `src/lib/mock/api.ts`.
- Images: fashion illustrations (women wearing each style) generated by `npm run art` into `public/products` and `public/art`.
  Replace them with real photos of the same file names, or run `npm run images` (needs `OPENAI_API_KEY`) for AI images.
- Turn demo mode off with `NEXT_PUBLIC_API_URL=...` (real backend) or `NEXT_PUBLIC_USE_MOCK=false`.

## Backend contract this app expects (all JSON, `Authorization: Bearer <token>` when signed in)

| Area | Endpoints |
| --- | --- |
| Auth (see `src/lib/api/auth.ts`) | `POST /auth/login {username,password}`, `POST /auth/register {name,username,email,password}` → `{ token, user, profile? }`; `GET /auth/me`; `POST /auth/logout`; `POST /auth/password-reset {identifier}`; `POST /auth/password-reset/confirm {token,password}` (emailed link opens `/reset-password?token=...`); `PATCH /me/profile` |
| Catalog (public) | `GET /catalog/products`, `/catalog/categories`, `/catalog/collections`, `GET /products/by-ids?ids=a,b` → `{ products }` |
| Content (public) | `GET /content/settings`, `/content/homepage`, `/content/banners`, `/content/testimonials` |
| Cart | `GET /cart`, `PUT /cart`, `POST /cart/quote` → `{ quote }` |
| Checkout | `POST /checkout` → payment session, `POST /checkout/verify`, `POST /checkout/retry` |
| Orders | `GET /orders` → `{ orders }`, `GET /orders/:id`, `POST /orders/track` |
| Forms | `POST /contact`, `POST /newsletter` |

Errors: `{ "error": "message", "code"?: "..." }`. Shapes follow `src/lib/types.ts` and `src/lib/content.ts`.
